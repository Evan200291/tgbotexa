🛡️ VPN ထည့်သွင်းနည်း လမ်းညွှန်

သင်အသုံးပြုသော ဖုန်း သို့မဟုတ် ကွန်ပျူတာကို နှိပ်၍ အဆင့်ဆင့် ကြည့်ရှုပါ။

1. Play Store မှ Outline၊ Hiddify သို့မဟုတ် v2rayNG ကို ဒေါင်းလုဒ်ဆွဲပါ။
2. Key စာမျက်နှာမှ ss://... Key Link (သို့) Subscription Link ကို တစ်ချက်နှိပ်၍ Copy ကူးပါ။
3. App ကိုဖွင့်ပြီး '+' (Add Server) ကိုနှိပ်ပါ — Clipboard သို့မဟုတ် QR Code မှ ထည့်သွင်းပါ။
4. Connect ကိုနှိပ်၍ အသုံးပြုနိုင်ပါပြီ။
1. App Store မှ Outline သို့မဟုတ် Streisand ကို ထည့်သွင်းပါ။
2. ss://... Key Link ကို Copy ကူးပါ။
3. App ထဲတွင် '+' → Import from Clipboard (သို့) Scan QR ကို ရွေးပါ။
4. VPN Permission ကို Allow ပေးပြီး Connect လုပ်ပါ။
1. Outline Client သို့မဟုတ် Hiddify ကို ကွန်ပျူတာတွင် ထည့်သွင်းပါ။
2. ss://... Key Link ကို Copy ကူးပါ။
3. App ထဲတွင် Add Server / '+' ကိုနှိပ်ပြီး Key ကို Paste ထည့်၍ Connect နှိပ်ပါ။
